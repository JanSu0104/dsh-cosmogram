# Cosmogram · 命理解读助手

一个给 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 用的传统文化解读插件，同时附带一套可粘贴到任意大模型的通用提示词。

覆盖：**紫微斗数 / 八字四柱 / 六爻 / 奇门遁甲 / 风水 / 塔罗 / 星座星盘 / 姓名学 / 择日**。

## 它是做什么的

只做**解读**，不做**排盘**。你把本地排盘工具、截图、文字盘或第三方网站得到的盘面贴进来，它按固定七段式讲解，讲清楚"哪些能确定、哪些还不知道"，并拒绝用编造的星曜、卦象、牌意或行星度数填补空白。

| 会做 | 不会做 |
| --- | --- |
| 解读你贴的紫微、八字、六爻、奇门、风水、塔罗、星盘、姓名、择日资料 | 起盘、起卦、抽牌、布奇门、算星历 |
| 解读前先告诉你缺哪些必要元素 | 补写缺失的宫位、星曜、四化、干支、爻、牌位或度数 |
| 多体系分别陈述、解释冲突 | 把多个体系硬合成一个"唯一结论" |
| 给概率性判断、边界和追问方向 | 用"注定 / 一定 / 必发 / 死局"这类绝对表述 |
| 健康、法律、投资、心理、婚姻类自动附上边界提示 | 替代医生、律师、投资顾问或心理咨询 |

## 插件包含三个能力

1. **`cosmogram` 技能**：只在需要解读时加载。内含解读铁律、九大体系的解读顺序、术语白话对照、七段式输出模板、语气规范与安全边界。
2. **`cosmogram_intake` 工具**：解读前的确定性校验。传入原始盘面，返回：
   - `status: ready | need_data` 与每个体系的 `coverage` 覆盖率（0–100）；
   - 已具备 / 仍缺失的必要元素；
   - 只看关键词看不出来的**结构性问题**：时柱与所述钟点对不上、有四化却没生年天干、有动爻却无变卦；
   - 应当原样向用户提出的补充问题（绝不替你猜盘）；
   - **输入本身已经确定的要点**：八字十神、藏干、五行权重、冲合、旬空；星盘相位与元素/模式分布——全部由用户粘贴的盘面算出，不含任何历法或星历；
   - 七段式回答骨架；
   - 由主题触发的边界提示（健康、法律、投资、心理、婚姻）。
3. **`cosmogram_audit` 工具**：交付前自检。把写好的正文与原始盘面一起传入，检查七段是否齐全、有没有绝对化表述、敏感主题有没有专业边界、正文有没有引用输入里不存在的星曜/宫位/干支/牌名/度数。高优先级问题必须改完再交付。

工具里没有排盘，只有清单、查表与模板，所以它本身不可能编造盘面。

### 插件设置

插件声明了配置 schema，DSH 会据此渲染设置表单（插件页里该插件的配置项，或旧版宿主的“设置 → 插件”）。改完按新值执行，不需要重装：

| 设置 | 默认 | 作用 |
| --- | --- | --- |
| `strictness` | `balanced` | `strict` 要求必要元素齐全；`balanced` 缺项时做有限解读并注明缺口；`lenient` 只要覆盖率达到阈值就放行。 |
| `coverageThreshold` | `60` | `lenient` 模式下的覆盖率门槛（0–100）。 |
| `showFacts` | `true` | 是否在校验结果里附上推演要点。关闭可省 token。 |
| `auditMode` | `warn` | `off` 不提示；`warn` 只报告问题；`strict` 要求高优先级问题清零。 |

### 会话标签「命盘」

插件还会在对话标签栏加一个 **命盘** 标签：显示当前版本、两个已注册的工具、设置文件路径，并把上面四项做成可编辑控件。**保存设置** 立即生效并写入 profile 下的 `cosmogram.settings.json`；**恢复默认** 清除该文件。设置优先级为：默认值 → bundle 配置 → 标签里保存的值。

标签在前端，安装或更新后需要刷新页面（或重启应用）才会出现。

## 各体系最低数据要求

| 体系 | 最少需要 |
| --- | --- |
| 紫微斗数 | 十二宫（至少命宫与五个主要宫位）+ 三颗以上主星 + 生年四化；有性别与大限更完整 |
| 八字四柱 | 年、月、日、时四柱干支；有性别、大运、流年更完整 |
| 六爻 | 本卦与变卦、动爻、月建日辰（或准确起卦时间）；所问之事单独提供 |
| 奇门遁甲 | 阴阳遁与局数、九宫盘（八门/九星/八神/三奇六仪）；有值符值使更完整 |
| 风水 | 坐向或朝向、户型布局、门窗与功能区；有罗盘度数更完整 |
| 塔罗 | 牌阵名称与位置含义、牌名、正逆位 |
| 星座星盘 | 行星落座、宫位（上升）；有相位更完整（宫位需要出生时间地点） |
| 姓名学 | 姓名用字、笔画依据（繁体/简体）、三才五格或五行字义 |
| 择日 | 所办事项、可选日期范围；有主事人属相或八字更完整 |

`cosmogram_intake` 会把"最少需要"和"更完整"分开报告：可补充项不会挡住第一次解读。

只给出生时间时，它会说明本助手不排盘，列出上表最少需要的元素，并请你补充。

## 安装到 DeepSeek Harness

这是一个零依赖的 Host-only 插件包（`index.js` + 补丁 + 语言文件 + 图标 + Markdown 资源）。

**Web 界面**：打开 **插件（Plugins）** → **添加插件（Add plugin）** → 选择本目录。

**在会话里**：调用 `plugin_manager`，`action: "install_bundle"`，`target` 填本目录的绝对路径；若 `cosmogram` 一行安装后是禁用状态，再启用它。

**从 npm 安装（发布后）**：调用 `plugin_manager`，`action: "install_bundle"`，`target` 填 `dsh-cosmogram`；或在 **添加插件** 里直接输入包名。

本地目录安装会链接这份代码，所以改动在插件重新加载后生效。插件安装进 profile，会影响该 profile 下的所有会话；移除 bundle 即可还原。

**本地目录安装是软链接，文件夹一移动就会坏。** 插件管理器要从该路径读 `locale/` 和补丁，目录被移动或删除后会报 `Plugin metadata … ENOENT …/locale`，这一行插件随即加载失败。日常使用请从 registry 安装；开发时若移动了目录，删掉 bundle 重装一次，而不是改路径。

### 使用示例

```
体系：紫微斗数
数据来源：本地排盘工具
命盘：命宫在午，紫微、天相同宫；财帛宫武曲化禄；官禄宫七杀……
问题主题：事业
补充：最近想换工作，适不适合？
```

助手会先调用 `cosmogram_intake`，缺数据就先问，然后按下面七段输出。中文是常见输入，英文提问同样可用（技能与工具描述都是双语的）。

1. 当前使用的体系与数据来源
2. 关键信息摘要
3. 核心判断
4. 主要依据
5. 不确定或需要补充的信息
6. 可执行建议
7. 可继续追问的问题

没有提供任何盘面时，固定回复：

> 请提供具体命盘、卦象、牌阵或星盘信息。如果暂时没有，可以发出生时间、性别、出生地、问题主题，以及你希望使用的体系。

## 不装插件也能用

`prompts/` 里是同一套契约的通用版本：

- `prompts/cosmogram.prompt.md`：整段粘贴为系统提示 / 自定义指令 / Project 指令，适用于 ChatGPT、Claude、Gemini、DeepSeek、Qwen、Kimi 或本地模型；
- `prompts/cosmogram.spec.json`：九大体系与最低数据要求的机器可读清单，方便你自己写校验器或工具；
- `prompts/README.md`：使用说明，以及它与 DSH 插件的差别。

## 边界与免责

全部内容属**传统文化与娱乐参考**，不构成预测，也不构成专业建议。技能与工具共同保证：

- 不使用绝对化、宿命式表述，不制造恐慌；
- 健康、法律、投资、心理、婚姻类自动附边界提示；
- 不解读不在场第三方的隐私细节；
- 不推荐、不承诺任何"改运 / 消灾 / 开光"类付费服务。

塔罗、占星与中国术数本就可能互相矛盾；遇到分歧时，分别解释，不硬凑成一个结论。

```

lib/store.js          标签页设置的落盘读写
lib/routes.js         /__cosmogram/api（state / save / reset）
lib/tool.js           cosmogram_intake 与 cosmogram_audit 定义
lib/skill.js          cosmogram 技能注册
assets/cosmogram.md    技能正文（解读契约）
references/           分体系解读要点、输出范例、安全规则
prompts/              给其他社区用的通用提示词与规范
test/                 47 个测试：校验、覆盖率、推演、自检、清单、注册
cordis.patch.yml      bundle 补丁
locale/{en,zh}.json   插件管理器的标题与描述
icon.svg              原创图标（圆盘内三爻）
```

### 增加新体系

在 `lib/intake.js` 的 `SYSTEM_SPECS` 里加一项（含最低数据校验），同步 `prompts/cosmogram.spec.json`、`references/systems.md` 和两份 README。清单一致性测试会在两边不同步时失败。

## 发布到社区

这个包已经可以直接发布：MIT 许可、零运行时依赖、`files` 列全了所有资源、插件管理器所需的标题与描述来自 `locale/`。

1. 若 npm 上的 `dsh-cosmogram` 已被占用，改 `package.json` 里的包名（同时改 `cordis.patch.yml` 的 `name` 与 profile 依赖）。
2. 发布到公共 registry：`npm publish --registry=https://registry.npmjs.org`；只有带 scope 的包名（`@you/...`）才需要 `--access public`。
3. 给仓库加 `dsh-plugin`、`deepseek-harness`、`chinese-metaphysics`、`tarot`、`bazi` 等 topic。

从 registry 安装时解析的是同一份清单，图标、标题、描述不需要额外托管。
