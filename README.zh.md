# 命理解读助手 · dsh-suanming

一个给 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 用的传统文化解读插件，同时附带一套可粘贴到任意大模型的通用提示词。

覆盖：**紫微斗数 / 八字四柱 / 六爻 / 奇门遁甲 / 风水 / 塔罗 / 星座星盘 / 姓名学 / 择日**。

[English README](README.md) ｜ [MIT 许可](LICENSE)

---

## 它是做什么的

只做**解读**，不做**排盘**。你把本地排盘工具、截图、文字盘或第三方网站得到的盘面贴进来，它按固定七段式讲解，讲清楚"哪些能确定、哪些还不知道"，并拒绝用编造的星曜、卦象、牌意或行星度数填补空白。

| 会做 | 不会做 |
| --- | --- |
| 解读你贴的紫微、八字、六爻、奇门、风水、塔罗、星盘、姓名、择日资料 | 起盘、起卦、抽牌、布奇门、算星历 |
| 解读前先告诉你缺哪些必要元素 | 补写缺失的宫位、星曜、四化、干支、爻、牌位或度数 |
| 多体系分别陈述、解释冲突 | 把多个体系硬合成一个"唯一结论" |
| 给概率性判断、边界和追问方向 | 用"注定 / 一定 / 必发 / 死局"这类绝对表述 |
| 健康、法律、投资、心理、婚姻类自动附上边界提示 | 替代医生、律师、投资顾问或心理咨询 |

## 插件包含两个能力

1. **`suanming` 技能**：只在需要解读时加载。内含解读铁律、九大体系的解读顺序、术语白话对照、七段式输出模板、语气规范与安全边界。
2. **`suanming_intake` 工具**：解读前的确定性校验。传入原始盘面，返回：
   - `status: ready | need_data`；
   - 已具备 / 仍缺失的必要元素；
   - 应当原样向用户提出的补充问题（绝不替你猜盘）；
   - 七段式回答骨架；
   - 由主题触发的边界提示（健康、法律、投资、心理、婚姻）。

工具里没有任何命理计算，只是"清单校验 + 模板生成"，所以它本身不可能编造盘面。

## 各体系最低数据要求

| 体系 | 最少需要 |
| --- | --- |
| 紫微斗数 | 十二宫（至少命宫/身宫/财帛/官禄/夫妻/福德）+ 主星辅星 + 生年四化 + 性别 |
| 八字四柱 | 年、月、日、时四柱干支；有性别、大运、流年更完整 |
| 六爻 | 本卦与变卦、动爻、月建日辰（或准确起卦时间）、所问之事 |
| 奇门遁甲 | 阴阳遁与局数、九宫盘（八门/九星/八神/三奇六仪）、问事类别与时间 |
| 风水 | 坐向或朝向、户型布局、门窗与功能区；有罗盘度数更完整 |
| 塔罗 | 牌阵名称与位置含义、牌名、正逆位 |
| 星座星盘 | 出生日期时间地点、行星落座、宫位（上升）；有相位更完整 |
| 姓名学 | 姓名用字、笔画依据（繁体/简体）、三才五格或五行字义 |
| 择日 | 所办事项、可选日期范围、主事人信息；有忌避条件更完整 |

只给出生时间时，它会说明本助手不排盘，列出上表最少需要的元素，并请你补充。

## 安装到 DeepSeek Harness

这是一个零依赖的 Host-only 插件包（`index.js` + 补丁 + 语言文件 + 图标 + Markdown 资源）。

**Web 界面**：打开 **插件（Plugins）** → **添加插件（Add plugin）** → 选择本目录。

**在会话里**：调用 `plugin_manager`，`action: "install_bundle"`，`target` 填本目录的绝对路径；若 `suanming` 一行安装后是禁用状态，再启用它。

本地目录安装会链接这份代码，所以改动在插件重新加载后生效。插件安装进 profile，会影响该 profile 下的所有会话；移除 bundle 即可还原。

### 使用示例

```
体系：紫微斗数
数据来源：本地排盘工具
命盘：命宫在午，紫微、天相同宫；财帛宫武曲化禄；官禄宫七杀……
问题主题：事业
补充：最近想换工作，适不适合？
```

助手会先调用 `suanming_intake`，缺数据就先问，然后按下面七段输出：

1. 当前使用的体系与数据来源
2. 关键信息摘要
3. 核心判断
4. 主要依据
5. 不确定或需要补充的信息
6. 可执行建议
7. 可继续追问的问题

没有提供任何盘面时，固定回复：

> 请提供具体命盘、卦象、牌阵或星盘信息。如果暂时没有，可以发出生时间、性别、出生地、问题主题，以及你希望使用的体系。

## 不装插件也能用

`prompts/` 里是同一套契约的通用版本：

- `prompts/suanming.prompt.md`：整段粘贴为系统提示 / 自定义指令 / Project 指令，适用于 ChatGPT、Claude、Gemini、DeepSeek、Qwen、Kimi 或本地模型；
- `prompts/suanming.spec.json`：九大体系与最低数据要求的机器可读清单，方便你自己写校验器或工具；
- `prompts/README.md`：使用说明，以及它与 DSH 插件的差别。

## 边界与免责

全部内容属**传统文化与娱乐参考**，不构成预测，也不构成专业建议。技能与工具共同保证：

- 不使用绝对化、宿命式表述，不制造恐慌；
- 健康、法律、投资、心理、婚姻类自动附边界提示；
- 不解读不在场第三方的隐私细节；
- 不推荐、不承诺任何"改运 / 消灾 / 开光"类付费服务。

塔罗、占星与中国术数本就可能互相矛盾；遇到分歧时，分别解释，不硬凑成一个结论。

## 开发

```sh
npm test        # node --test，零依赖
npm run check   # 逐个模块语法检查
```

```
index.js              插件入口：注册技能与工具
lib/intake.js         零依赖的校验、体系识别、骨架生成
lib/tool.js           suanming_intake 工具定义
lib/skill.js          suanming 技能注册
assets/suanming.md    技能正文（解读契约）
references/           分体系解读要点、输出范例、安全规则
prompts/              给其他社区用的通用提示词与规范
test/                 26 个测试：校验逻辑、清单、注册
cordis.patch.yml      bundle 补丁
locale/{en,zh}.json   插件管理器的标题与描述
icon.svg              原创图标（卦象标记）
```

增加新体系：在 `lib/intake.js` 的 `SYSTEM_SPECS` 里加一项（含最低数据校验），同步 `prompts/suanming.spec.json`、`references/systems.md` 和两份 README。清单一致性测试会在两边不同步时失败。
