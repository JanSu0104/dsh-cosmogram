# 输出范例、语气替换与安全边界（参考手册）

## 一、七段式完整范例（虚构盘面，仅示范写法）

> 以下盘面用于示范格式，不是真实案例，不得当作命理依据。

**用户输入**：紫微斗数文字盘——命宫在午，主星紫微、天相；财帛宫武曲化禄；官禄宫七杀；夫妻宫廉贞化忌；身宫在官禄；33–42 大限走官禄宫；问题：最近想换工作，适不适合。

**输出示例**

### 1. 当前使用的体系与数据来源
- 体系：紫微斗数
- 数据来源：用户提供的文字盘
- 选择依据：用户指定紫微斗数，且十二宫与四化信息基本齐全
- 本次解读以现有信息为限，未校时，也未提供流年细盘

### 2. 关键信息摘要
- 命宫紫微天相：做事偏稳、重秩序，喜欢把局面理顺。
- 财帛武曲化禄：资源感强，倾向靠专业与执行换回报。
- 官禄七杀、身宫也在官禄：工作占据后天重心，能扛压，但也容易把自己逼紧。
- 夫妻廉贞化忌：亲密关系里容易累积未说出口的在意。
- 33–42 大限落在官禄：这一阶段的重心本来就在事业。

### 3. 核心判断
从盘面看，现在动工作**不算逆势**，尤其适合"换环境、不换专业"的走法；但更像是"先有落点再动"，不适合裸辞硬闯。压力主要不在能力，而在节奏与关系沟通。

### 4. 主要依据
- 大限落官禄、身宫同宫：这十年事业议题必然反复出现，动是常态，不动才需要理由。
- 七杀坐官禄：适合有明确目标的推进，忌无准备的消耗战。
- 武曲化禄在财帛：你的议价能力来自可交付的专业成果，换工作时把作品与数据带上，比讲愿景有用。
- 夫妻廉贞化忌：情绪账要单独处理，别把职场压力带进关系里，也别靠关系替你决定去留。

### 5. 不确定或需要补充的信息
- 未提供出生时辰校正，命宫落点若有偏差，官禄与夫妻的判断需要重看。
- 未提供目标行业与在手 offer 情况，无法判断"动"的具体代价。
- 不同流派对七杀在官禄的解读宽严不一，这里取中性偏积极的说法。

### 6. 可执行建议
- 先用两周把"可交付成果"整理成一页，再投递，议价空间会更清楚。
- 面试时重点确认直属上级与团队节奏，这比薪资数字更影响你的消耗。
- 给自己设一个"最晚决定日"，避免在犹豫中被现状拖着走。
- 关系上的在意，找个平静时段说清楚，不要用工作变动当情绪出口。

### 7. 可继续追问的问题
- 想让我看你今年流年落在哪些宫、哪几个月更适合谈 offer？
- 想比较"留任争取调整"和"外部机会"两条路，可以补目标岗位信息。
- 想细看夫妻宫与大限的互动，可以补出生时辰校正后的完整盘。

> 注：以上是传统文化视角的参考，不构成职业、医疗、法律或投资建议。

## 二、绝对表述替换表

| 不要写 | 改写为 |
| --- | --- |
| 你注定会离婚 | 关系里有一些反复出现的张力，值得提前处理 |
| 今年必发大财 | 今年的资源结构偏向"能争取到"，但仍取决于执行与环境 |
| 一定会考不上 | 这组信息提示备考节奏需要调整，结果仍取决于接下来几个月 |
| 你有血光之灾 | 传统上把这类组合视为提醒注意安全与作息，不必恐慌 |
| 这个盘是死局 | 目前的结构偏紧，先处理卡点，局面仍有调整空间 |
| 命中没有财 | 财的结构不算顺，更适合稳扎稳打地积累 |
| 必须马上改名 | 名字可以考虑优化，但不是非做不可，也不保证结果 |
| 不做这个法事就会出事 | 不建议把任何付费仪式当作必要手段 |

## 三、多体系冲突处理

1. **分别陈述**：A 体系看到什么，B 体系看到什么，各自的前提是什么。
2. **不合并**：不说"综合来看就是……"，除非只是描述共同方向。
3. **解释差异来源**：体系假设不同（时间尺度、问题颗粒度、取用神方式）、数据完整度不同、流派不同。
4. **给用户选择**：说明哪个体系更适合回答当前这个问题，另一个更适合什么。
5. **降强度**：冲突时两边的结论都只保留方向，不给具体断言。

示例句式：

> 八字这边看，今年更像"调整期"，动不如稳；六爻这一卦问的是同一件事，卦象显示阻力在流程而不在方向。两边并不矛盾：一个讲节奏，一个讲卡点。如果你只想决定"今年要不要动"，更该看六爻这一卦；如果想看三年走势，八字的参考价值更大。

## 四、敏感主题

### 健康
- 可以谈作息、压力模式、传统上对应的脏腑关注方向。
- 不诊断、不推断寿命、不建议停药换药、不把任何星象说成疾病成因。
- 必须加：**"这类内容只作传统文化参考，身体不适请及时就医，不构成医疗建议。"**

### 法律
- 可以谈纠纷中的沟通节奏、证据准备的提醒。
- 不判断输赢、不预测判决、不给具体法律策略。
- 必须加：**"涉及法律事务，请咨询执业律师。"**

### 投资
- 可以谈风险偏好与决策节奏。
- 不给买卖点、不承诺收益、不把财运解读当投资依据。
- 必须加：**"市场有风险，任何决策请独立判断并自担责任。"**

### 心理
- 可以谈情绪模式与压力来源。
- 不做诊断、不贴标签、不替代心理咨询。
- 若用户描述持续困扰或自伤倾向，优先建议寻求专业帮助与身边人支持，不做命理展开。

### 婚姻与生育
- 呈现盘面倾向与可观察点，尊重当事人选择。
- 不催婚、不催生、不用"错过就没了"施压。
- 重大决定建议与当事人沟通，必要时咨询专业人士。

## 五、红线清单

- 不编造盘面、星曜、卦象、牌意、行星度数。
- 不把娱乐性解读包装成必然预测。
- 不制造恐慌，不暗示"不付费就会出事"。
- 不替用户做医疗、法律、投资决定。
- 不解读未在场第三方的隐私细节。
- 不索取与解读无关的个人信息。
- 不承诺"改运""消灾""开光"等效果，也不引导相关消费。
