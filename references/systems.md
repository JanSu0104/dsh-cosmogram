# 九大体系的解读要点（参考手册）

本文件只讲"拿到数据后怎么读"，不教排盘。每个体系固定五块：最低数据、解读顺序、术语白话、能答与不能答、可追问方向。解读时按需取用，不要整段复述给用户。

---

## 1. 紫微斗数

**最低数据**：十二宫（至少命宫、身宫、财帛、官禄、夫妻、福德）＋宫中主星辅星＋生年四化（禄权科忌）＋性别；有出生年月日时与大限更完整。

**解读顺序**
1. 命宫与身宫：先看主轴，再看"后天用力点"在身宫。
2. 三方四正：命宫、财帛、官禄、迁移互相参照，判断格局是否成势。
3. 四化落宫：化禄看资源来处，化权看掌控点，化科看名声与贵人，化忌看卡点与执念。
4. 大限与流年：先定阶段主题，再谈具体年份，不越级。

**术语白话**
- 三方四正：一件事的三个侧面加上外部环境。
- 四化：事情的四种作用力（资源、掌控、名声、阻碍）。
- 空宫：该领域没有主星坐守，常表示"需借对宫或后天补"，不等于坏事。
- 煞星：提示摩擦与代价，不是灾祸判决。

**能答**：结构性格局、资源与压力分布、阶段重心、人际模式、适合的用力方向。
**不能答**：精确事件日期、对方心里怎么想、健康诊断、投资标的。
**追问方向**：换工作的时间窗口、某个大限的侧重、六亲关系的相处方式。

## 2. 八字四柱

**最低数据**：年柱、月柱、日柱、时柱（天干地支）；有性别、大运起运、当前流年更好。

**解读顺序**
1. 日主（日干）与月令：定强弱基调，先看"得令、得地、得势"。
2. 五行分布与缺旺：看哪一行过旺、哪一行受制。
3. 十神结构：比劫、食伤、财、官杀、印，看资源与压力的来源。
4. 大运流年：先讲阶段趋势，再落到具体年份，注明"未校真太阳时"等不确定项。

**术语白话**
- 日主：代表"你自己"的那个字。
- 十神：把五行关系翻译成社会角色（同伴、产出、资源、约束、支持）。
- 身强身弱：不是好坏，是"该往外用还是往里补"的用力方式。
- 用神喜忌：传统上认为对结构有帮助的方向，属倾向性建议，不是命令。

**能答**：性格与做事方式、资源结构、阶段节奏、适合的环境与协作方式。
**不能答**：具体婚期、精确财运数字、疾病诊断、官司结果。
**追问方向**：某步大运的重点、换城市/换行业的方向性、合作关系中的角色。

## 3. 六爻

**最低数据**：本卦与变卦、动爻、月建与日辰（或起卦时间）、所问之事；有世应、六亲、六神更完整。

**解读顺序**
1. 定用神：先确认这一问问的是什么（财、官、文书、感情、健康等对应不同爻）。
2. 看用神旺衰：结合月建日辰，判断有力无力。
3. 看生克冲合：谁帮它、谁制它、有没有被合住或冲动。
4. 看动爻与变爻：变化的方向与代价。
5. 谈应期：用"可能在……前后出现变化"表述，不锁定某日。

**术语白话**
- 用神：这一问的"主角爻"。
- 旺衰：主角在当前时间点有没有力气。
- 动爻：会变化的那一爻，代表变量。
- 应期：事情可能有反应的时段，属概率性提示。

**能答**：单件事的当下走势、阻力来源、推进节奏、可观察的信号。
**不能答**：一卦多问、替他人问隐私、精确到日的保证。
**追问方向**：换个角度再起一卦前，先确认问题是否同一件事；补充月建日辰后细化应期。

## 4. 奇门遁甲

**最低数据**：阴阳遁与局数、九宫盘（八门、九星、八神、三奇六仪）、问事类别与时间；有值符值使更完整。

**解读顺序**
1. 定用神：按问事类别取用神（求财、求职、感情、出行、合作等）。
2. 看用神落宫：宫位五行、门星神组合，判断环境与助力。
3. 看宫与宫的生克：我与事、人与环境之间是相生还是相制。
4. 看格局与时机：吉格看能否借势，凶格看需要规避什么。
5. 谈方位与时机：给"更适合往哪个方向、哪个时段推进"的倾向。

**术语白话**
- 局：这一盘的时空编号。
- 八门：事情的通道（开、休、生、伤、杜、景、死、惊）。
- 值符值使：这一盘的"主导力量"与"执行力量"。
- 用神落宫：主角在当前环境里的位置。

**能答**：某件事在特定时空下的配合度、方位与节奏倾向、协作关系。
**不能答**：没有盘面时的方位建议、替代法律与投资判断、精确结果。
**追问方向**：换时间窗口再盘、同一件事的不同阶段、合作对象的匹配度。

## 5. 风水

**最低数据**：房屋坐向（或朝向）、户型/平面布局、门窗与主要功能区位置；有罗盘度数、周边环境、居住人信息更完整。

**解读顺序**
1. 先形峦：外部环境、采光通风、动线、缺角与压迫感。
2. 再理气：坐向与方位对应的传统判断（注明流派差异）。
3. 落到功能区：卧室、厨房、书桌、入户的常见调整点。
4. 给可执行的微调：优先不装修、不砸墙、不花钱就能做的调整。

**术语白话**
- 坐向：房子背靠与面向的方向。
- 形峦：肉眼可见的环境形状与关系。
- 理气：按方位与时间推算的传统规则。
- 煞：传统上认为会带来摩擦的环境特征，不等于灾祸。

**能答**：布局与动线的改善点、功能区安排、可观察的环境因素。
**不能答**：不见现场就断言吉凶、要求大额改造或购买物件、替代建筑安全评估。
**追问方向**：单间布局、办公位调整、租房可做的最小改动。

## 6. 塔罗

**最低数据**：牌阵名称与每个位置的含义、抽到的牌名、正位或逆位；有问题背景与时间范围更好。

**解读顺序**
1. 先读牌阵结构：每个位置问的是什么。
2. 逐位读牌：牌意 + 位置含义，避免脱离位置套牌意。
3. 看牌与牌的关系：重复牌组、大牌小牌比例、正逆位分布、首尾呼应。
4. 收束成一个可行动的方向，而不是宿命结论。

**术语白话**
- 牌阵：把问题拆成几个格子的提问方式。
- 正位/逆位：同一张牌的两种表达，逆位常指"延迟、内化、受阻或过度"。
- 大牌：主题性、阶段性的力量；小牌：日常层面的具体动力。
- 切牌/指示牌：辅助定位，不改变主牌阵结论。

**能答**：当下心理动力、选择的代价、关系中的互动模式、近期可观察的变化。
**不能答**：医学诊断、他人隐私、精确日期、替代当事人做决定。
**追问方向**：同一问题的"如果这样做"分支、三个月后的复盘牌阵、关系双方的各自立场（需本人参与）。

## 7. 星座星盘

**最低数据**：出生日期、时间、地点（用于确定上升与宫位）＋行星落座；有宫位、相位、宫主星更完整。注意：没有星盘数据时不自行推算。

**解读顺序**
1. 太阳、月亮、上升：核心性格、情绪需求、外在呈现。
2. 宫位分布：人生重心落在哪些领域。
3. 相位：行星之间的协作或拉扯，看张力所在。
4. 宫主星与定位：把分散的信息串成一条线。
5. 行运（如有）：只谈趋势与可观察点，不给事件预言。

**术语白话**
- 上升：对外呈现的方式与起步姿态。
- 相位：行星之间的角度关系，代表内部互动。
- 宫位：生活的不同领域。
- 行运：当下的天体位置与出生盘的互动，表示阶段性主题。

**能答**：性格底色、情绪模式、关系需求、阶段主题、适合的节奏。
**不能答**：未提供时间地点却精确到宫的判断、健康诊断、投资建议。
**追问方向**：某个行运阶段的重点、职业方向的偏向、关系中的需求差异。

## 8. 姓名学

**最低数据**：姓名用字、笔画依据（繁体/康熙字典或简体）、三才五格或五行归类；有出生信息用于对照更完整。

**解读顺序**
1. 先看字义与音形：这是最容易被忽略、也最贴近日常的部分。
2. 再看笔画与五格：说明依据的是哪套笔画标准。
3. 看三才配置：传统上的搭配倾向。
4. 收束到"用字与称呼层面的观察"，不建议改名消费。

**术语白话**
- 三才：天格、人格、地格的传统配置说法。
- 五格：按笔画数理划分的五种格。
- 笔画：不同字典标准会不同，必须先确认依据。

**能答**：名字的语感与含义、称呼带来的印象、用字层面的补充观察。
**不能答**：改名就能改运的断言、精确笔画对应的必然吉凶、替代本人性格判断。
**追问方向**：取名的用字偏好、英文名与中文名的呼应、称呼场景的调整。

## 9. 择日

**最低数据**：所办事项、可选日期范围、主事人信息（属相/八字/性别）；有忌避条件与地点更好。

**解读顺序**
1. 明确事项性质：婚嫁、开业、动土、搬迁、签约、出行等，各有传统宜忌。
2. 先排冲突：主事人属相与日辰的冲、煞，先排除明显不宜的日子。
3. 再看宜忌：建除十二神、黄道吉日、传统宜忌条目。
4. 给区间而不是单点：列出 2–5 个候选，说明各自取舍。
5. 提醒现实约束：场地、交通、参与者时间永远优先于传统宜忌。

**术语白话**
- 建除十二神：传统给日子分类的一套标签。
- 黄道日：传统上认为较顺的日子。
- 冲煞：与主事人属相相冲的日子。
- 宜忌：传统历书给出的建议条目。

**能答**：日期区间的取舍、传统宜忌的对照、需要避开的冲突点。
**不能答**：替代审批与安全评估、保证某日必成、医疗手术日期的专业建议。
**追问方向**：备选日期的比较、仪式流程的传统讲究、与参与者时间的协调。

---

## 附：跨体系通用原则

- 同一件事只用一个体系做主解读，另一个体系只作旁证，避免"多盘混断"。
- 结论强度与数据完整度成正比：数据越少，措辞越保守。
- 先回答用户问的那件事，再补充"还看到什么"。
- 任何体系都不能替代用户自己的判断与现实约束。
